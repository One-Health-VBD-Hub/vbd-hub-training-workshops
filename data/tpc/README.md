# Thermal performance curve data

These snapshots support the November 2026 TPC workshop. They were retrieved from the public VecTraits API on 5 November 2026. `datasets.csv` records dataset IDs, source DOIs, units, expected record counts and retrieval dates. Chloe/Francis should review the challenge choices before the event.

`vectraits_raw.csv` preserves all returned fields for the three selected datasets, including record IDs, life stage, sex, experimental context, errors and citations. The three smaller CSVs are sorted teaching tables generated by `scripts/prepare_tpc_data.R`. Their `temp` field comes from `Interactor1Temp` (assay temperature, Celsius); `rate` comes from `OriginalTraitValue`, with its original unit retained. In dataset 56, `rate` is a survival percentage, not a rate per unit time.

Run from the repository root:

```r
source("scripts/prepare_tpc_data.R") # regenerate tables from the raw snapshot
```

To refresh the snapshot through `ohvbd` and regenerate the tables:

```sh
Rscript scripts/prepare_tpc_data.R --refresh
```

Preparation deliberately checks the recorded counts and context. A changed upstream dataset should trigger inspection rather than silently changing the worked example. Refreshing updates the retrieval dates; review the resulting diff before committing it.

These are curated study summaries, not a collection of independent individual-level replicates. Nearby digitised temperatures should not be treated as extra experimental temperature treatments without consulting the original paper. Missing replicate counts and incomplete error metadata limit uncertainty analyses. Keep genuine zero performance values. Do not weight by incomplete error fields or invent replicate counts.

Original studies:

- Yang et al. (2009), *Assessing the effects of temperature on the population of Aedes aegypti the vector of dengue*: [10.1017/S0950268809002040](https://doi.org/10.1017/S0950268809002040).
- Bayoh and Lindsay (2003), *Effect of temperature on the development of the aquatic stages of Anopheles gambiae sensu stricto*: [10.1079/BER2003259](https://doi.org/10.1079/BER2003259).

The VecTraits records credit Pawar et al. (2024), *Variation in temperature of peak trait performance constrains adaptation of arthropod populations to climatic warming*, as the curation source: [10.1038/s41559-023-02301-8](https://doi.org/10.1038/s41559-023-02301-8). Retain both the original-study and curation credits when using the data; software citations are additional.

The [MQB teaching CSV](https://github.com/MulQuaBio/MQB/blob/main/content/data/aedes_fecund.csv) contains 12 Yang-labelled and 18 Beserra-labelled rows. Dataset 474 closely matches the Yang subset, with different digitised values and two exact zeros. It is not the complete pooled MQB dataset, and its values must not be silently substituted or combined with it. No Beserra records were found in the repository's existing *A. aegypti* export.

API endpoints follow `https://vectorbyte.crc.nd.edu/portal/api/vectraits-dataset/{DatasetID}/?format=json`. The practical displays the equivalent `ohvbd` retrieval but renders from saved figures generated using the teaching table. The website build makes no live data API calls and does not rerun the TPC fitting.
